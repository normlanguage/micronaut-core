# micronaut-core sample ownership

[English](README.md) | [简体中文](README.zh-CN.md)

This module supplies introspection annotations and shared compile-time contracts. The runnable scenario is owned by [di](https://github.com/normlanguage/di/tree/main/samples) in its `samples/` directory; use that example to observe the behavior through the public API.

The module identity and pinned dependencies are defined in [module.norm](../micronaut/core/module.norm).
